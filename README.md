# ⚛️ منصة التنسيق البيداغوجي لأساتذة العلوم الفيزيائية
### النظام المتكامل لتنسيق الفروض والاختبارات ومتابعة التوزيع السنوي الرسمي

---

## 🌟 مميزات المنصة

### 1. تنسيق الفروض والاختبارات المدرسية:
- حجز مواضيع الفروض والاختبارات من قبل الأساتذة قبل موعدها.
- إمكانية التعاون الثنائي بين أستاذين لإعداد وتدقيق موضوع واحد.
- تحديث حالة الموضوع (متاح 🟢 ➔ قيد الإعداد ⏳ ➔ جاهز للمراجعة 🔍 ➔ معتمد للطباعة ✅).

### 2. التوزيع السنوي والتأشير الأسبوعي:
- **تضمين التوزيعات السنوية الرسمية الكاملة (2026/2027)** لجميع الشعب والمستويات الثانوية السبعة:
  1. **السنة الثالثة:** 3 علوم تجريبية (3AS SE)
  2. **السنة الثالثة:** 3 تقني رياضي + رياضيات (3AS TM/M)
  3. **السنة الثانية:** 2 علوم تجريبية (2AS SE)
  4. **السنة الثانية:** 2 تقني رياضي + رياضيات (2AS TM/M)
  5. **السنة الثانية:** 2 آداب وفلسفة (2AS LPh)
  6. **السنة الأولى:** 1 جذع مشترك علوم وتكنولوجيا (1AS TC-ST)
  7. **السنة الأولى:** 1 جذع مشترك آداب (1AS TC-L)
- جدول تفاعلي أسبوعي (من الأسبوع 01 إلى الأسبوع 30) بالتواريخ والوحدات والنسب المئوية والوقفات التقويمية والعطل.
- حساب نسبة التقدم في البرنامج تلقائياً فور تأشير الأستاذ على الحصة.
- لوحة مقارنة تقدم جميع أساتذة المؤسسة جنباً إلى جنب لكل مستوى.

### 3. لوحة تحكم منسق المادة:
- إضافة وتعديل الأساتذة وتعيين كلمة المرور البسيطة (PIN) لكل أستاذ.
- إضافة وتعديل الأقسام وتوزيع الإسناد التربوي.
- إضافة مواضيع وفروض جديدة للتنسيق.
- تعديل رمز بوابة المؤسسة (افتراضياً `0001`) ورمز المنسق (افتراضياً `0000`) والسنة الدراسية.

### 4. استخراج التقرير الرسمي للطباعة (A4):
- تقرير دوري متوافق مع معايير وزارة التربية الوطنية الجزائرية، جاهز للتوقيع من طرف أستاذ المنسق، ومفتش المادة، ومدير الثانوية.

## 🔑 بيانات الدخول الافتراضية

| الدور | الاسم | كلمة المرور / PIN | الصلاحيات |
| :--- | :--- | :---: | :--- |
| **بوابة الموقع** | رمز بوابة المؤسسة العامة | `0001` | فتح المنصة لجميع الأساتذة |
| **أستاذ منسق** | **الأستاذ بن محمد أيوب** | `0000` | كامل صلاحيات الإشراف والإدارة + أقسامه |
| **أستاذ مادة** | الأستاذ عبية | `1111` | حجز الفروض والتأشير على أقسامه ومتابعة الزملاء |
| **أستاذ مادة** | الأستاذ مختاري | `2222` | حجز الفروض والتأشير على أقسامه ومتابعة الزملاء |
| **أستاذة مادة** | الأستاذة بن سالم | `3333` | حجز الفروض والتأشير على أقسامها ومتابعة الزملاء |
| **أستاذ مادة** | الأستاذ قاسم | `4444` | حجز الفروض والتأشير على أقسامه ومتابعة الزملاء |

*(يمكن للمنسق تعديل أو إضافة أي أستاذ أو كلمة مرور في أي وقت).*

## 🚀 كيفية تشغيل المنصة

### التشغيل الفوري المباشر:
```bash
npm start
```
أو:
```bash
node server.js
```
ثم افتح المتصفح على الرابط:
👉 **`http://localhost:5000`**

### تشغيل وضع التطوير (Hot Reload):
```bash
npm run dev
```
